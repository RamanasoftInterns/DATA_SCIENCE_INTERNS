Things to try

  • Switch to Spiral with only [2] neurons in one hidden layer — watch it fail to separate the classes. That's underfitting.
  • Set learning rate near the top of the slider — watch the loss curve spike and oscillate instead of settling. That's too high a learning rate.
  • Push L2 regularization high — the boundary goes soft and blurry as weights are forced toward zero.
  • Compare Sigmoid vs ReLU on Spiral with 3 layers — sigmoid trains visibly slower. That's vanishing gradient in action.
  • Set every hidden layer to 0 neurons — the boundary can only ever be a straight line, exactly like a lone perceptron.
